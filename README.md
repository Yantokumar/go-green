## 🌟 Overview

**GoGreen** is an open-source GitHub contribution matrix visualizer, interactive heatmap painter, and streak automation toolkit designed to empower developers with full visual control over their GitHub activity calendar.

### ✨ Key Features

- 🎨 **Interactive Matrix Painter**: Draw custom patterns, pixel art, or text across a 53-week GitHub contribution grid.
- ⚡ **Ultra-Fast Stream Engine**: Powered by `git fast-import`, allowing the generation of thousands of backdated commits in under two seconds.
- 📊 **Dynamic Streak & Stats**: Live calculations of current streak, commit densities, and green-day percentages.
- 🌈 **Multiple Color Palettes**:
  - *Classic Emerald* (GitHub Standard Greens)
  - *Cyberpunk Matrix* (Electric Neon Green & Glow)
  - *Forest Moss & Teal* (Natural organic shades)
  - *Synthwave Sunset* (Retro purple & magenta)
  - *Solar Flare* (Warm golden amber)
- 🔊 **Synthesizer Feedback**: Real-time musical audio chimes while painting using the Web Audio API.
- 💻 **Multi-Language Exporter**: Instant export to Python, Bash, or JSON commit automation scripts.

## 🚀 Quick Start

### 1. Run the Web Application Locally

Open `index.html` directly in any modern browser:

```bash
# Clone the repository
git clone https://github.com/Yantokumar/go-green.git
cd go-green

# Open index.html directly
start index.html  # On Windows
# or open index.html on macOS / Linux
```

### 2. Using the Automated Contribution Generator

The automated generator script creates clean, verified backdated commits for every day of the calendar year:

```bash
python scripts/generate_green.py
```
